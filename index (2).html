Supabase SQL Editor-এ রান করার জন্য প্রস্তুত সম্পূর্ণ ডেটাবেজ টেবিল এবং পারমিশন স্ক্রিপ্ট।

৩ ধাপে Supabase সেটাপ করুন:

  1. Supabase Dashboard এ লগইন করে আপনার প্রজেক্টের SQL Editor ট্যাবে যান।
  2. উপরে দেওয়া সবুজ বাটনে ক্লিক করে সম্পূর্ণ SQL কোডটি কপি করে পেস্ট করুন।
  3. Run (Ctrl+Enter) চাপুন। সকল টেবিল (Articles, Categories, Files, Quizzes) সাথে সাথে তৈরি হয়ে যাবে!

GitHub ও Vercel ডিপ্লয়মেন্ট নির্দেশিকা

আপনার নিজস্ব ডোমেইন বা Vercel.app দিয়ে সম্পূর্ণ ফ্রিতে হোস্ট করার সহজ ধাপ।

ধাপ ১: GitHub এ রিপোজিটরি তৈরি করুন

  1. github.com/new এ গিয়ে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: knowledge-portal)।
  2. উপরে ডানদিকের "Download HTML" বাটন থেকে এই ফাইলটি ডাউনলোড করে নাম দিন index.html।
  3. GitHub রিপোজিটরিতে index.html ফাইলটি আপলোড (Commit) করে দিন।
▲

ধাপ ২: Vercel.com এ ডিপ্লয় করুন

  1. Vercel Dashboard এ গিয়ে "Add New... > Project" সিলেক্ট করুন।
  2. আপনার GitHub এর knowledge-portal রিপোজিটরিটি সিলেক্ট করুন।
  3. কোনো বিল্ড কমান্ড পরিবর্তনের প্রয়োজন নেই। সরাসরি "Deploy" বাটনে ক্লিক করুন!
  4. ১০ সেকেন্ডের মধ্যে আপনি আপনার নিজস্ব https://your-portal.vercel.app লিংক পেয়ে যাবেন।

Supabase কানেকশন কনফিগারেশন
